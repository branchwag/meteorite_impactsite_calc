1. Coordinate Conversion (LLA → ECEF)

All lat/lon/altitude inputs are converted to Earth-Centered Earth-Fixed (ECEF) cartesian coordinates (R = 6,371,000 m):

r = R + altitude
x = r·cos(lat)·cos(lon)
y = r·cos(lat)·sin(lon)
z = r·sin(lat)

2. Scenarios 1 & 2

Both scenarios use the same inputs (fireball end time, dark-flight start altitude, and a radar return point) and run the same A/B/C analysis below. Scenario 2 additionally predicts where to look on radar: starting from the radar point, the rock is descended vertically (direction = −position/|position|) through the standard atmosphere for an assumed 100 g chondrite, reporting the predicted lat/lon and clock time at each lower altitude (with optional per-layer wind correction), down to the ground.

3. Standard Atmosphere

Air density ρ(h) and gravity g(h) are interpolated from the ISA table (0–33 km, 1 km steps):

Alt (km)  ρ (kg/m³)   g (m/s²)
   0       1.2250      9.0807
  10       0.4127      9.0665
  20       0.0880      9.0523
  24       0.0463      9.0466
  30       0.0180      9.0382

4. Terminal Velocity

Full physics formula (force balance at terminal velocity), ρ and g re-evaluated at each altitude step:

V = √( 8·D·g(h)·r / (3·ρ(h)·Cd) )

D  = meteorite bulk density (kg/m³)
r  = radius from M = (4/3)π r³ D
ρ  = air density at altitude h
Cd = drag coefficient (Settings panel, default 0.8)

Default densities: OC 3.3 · CC 2.7 · Iron 7.2 g/cm³ (all editable in Settings).

5. Section A — Type of Meteorite

Observed fall time Δt = radar_hit_UTC − fireball_end_UTC (seconds). For each meteorite type, a binary search (log scale, 2 g–10 kg) finds the mass whose integrated fall time matches Δt:

T_fall = ∫[h_radar → h_dark] dh / V_t(h, m, D, Cd)

Sanity checks: dark flight altitude 18–33 km · Δt 60–600 s · radar alt below dark flight alt.

6. Section B — Number of Rocks in the Air

Uses the radar range equation with equivalent reflectivity Ze. Geometric backscatter (accurate for D ≥ λ):

σ = π r²   (geometric)
Ze = (λ⁴ / π⁵|K|²) · Σσ / V_r

Rayleigh formula (Z = ΣD⁶/V_r, accurate for D ≪ λ) also shown for comparison.

7. Section C — Wind Correction & Ground Location

Starting from the radar hit, the fragment falls straight down in 1 s steps. Terminal velocity and wind drift are applied at each step using the Standard Atmosphere:

  1. Compute V_t(h) at current altitude
  2. pos += direction × V_t
  3. Apply wind: pos += R_enu · wind_enu
  4. Stop at altitude 0
